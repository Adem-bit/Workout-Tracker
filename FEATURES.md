# Features

## Workout logging

- Add exercises with sets, reps and weight
- Bodyweight shorthand (type 'bw')
- Optional notes per workout
- Edit and delete workout

## Tracking

- Personal records per exercise
- Progress charts with Chart.js
- Stats dashboard (total workouts, streaks, favorites)

## Data

- CSV export
- Text export
- Filter by exercise

## UI

- Dark green navbar with active highlighting
- Responsive desing
- Empty states with motivational quotes
