# Workout Tracker

A minimalist workout journal built with Flask and SQLite. Log exercises, track sets and reps, and monitor progress over time with interactive charts.

## Features

- Add, edit, and delete workouts
- Personal records tracking
- Progress charts with Chart.js
- Filter workouts by exercise
- Export to CSV and text
- Input validation

## How to Run

1. Install Flask: `pip install flask`
2. Run: `python app.py`
3. Open: `http://127.0.0.1:5000`

## Tech Stack

- **Backend:** Python, Flask
- **Database:** SQLite
- **Frontend:** HTML, CSS, Jinja2, Chart.js
- **Version Control:** Git, GitHub
